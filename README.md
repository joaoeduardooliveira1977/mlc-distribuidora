# Um mimo para você — Loja virtual

Protótipo inicial em Next.js + TypeScript.

## Rodar localmente
1. Instale Node.js 20+.
2. Abra esta pasta no terminal.
3. Rode `npm install` e depois `npm run dev`.
4. Abra http://localhost:3000
